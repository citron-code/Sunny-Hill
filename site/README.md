# The games site (technical notes)

Turkish guides for the teacher: [KURULUM.md](KURULUM.md) (setup and updates), [VELI-REHBERI.md](VELI-REHBERI.md) (parents). The look: [DESIGN.md](DESIGN.md).

One Cloudflare Worker on workers.dev: the static files in `dist/` (Workers static assets), `server/worker.js` for `/api/*`, and a D1 (SQLite) database. Not Pages: all of `pages.dev` has been blocked in Turkey since November 2025.
The games are copied in as they are published, with one script tag added; their files are never edited.

| Path | What |
| --- | --- |
| `shared/games.js` | The game list: ids, the browser-storage keys that make up each save (`keys` or `prefix`), the summary line. Used by the pages, the bridge, the server and `../tasi.html`. |
| `shared/config.js` | The site's name (`name`, `short`: `build.mjs` puts them into every page and the home-screen app as `{{AD}}`, `{{KISA}}`), its addresses (`siteOrigins`: where `tasi.html` may send old saves) and the old address. |
| `tools/make-pixels.mjs` | The pixel art, drawn as text: the front page's mascot `img/maskot.svg` (the little orange, 32 x 32, six frames: idle, blink, two waves, squash, hop; `site.css` plays them), the icon tile `img/logo.svg` (the same mascot, standing still, on night blue), the scenery in `img/px/` and the icons in `img/i/`. Then `node tools/make-icons.mjs` draws the PNG icons from the logo (and `icon-maskable-512.png`, the tile smaller on night blue, for phones that cut icons to a circle). |
| `public/js/hero.js`, `public/js/valley.js`, `public/js/pq-world.js`, `public/js/pq-cast.js`, `public/img/pq-cast.png` | The front page as a game title screen: the Citrobit valley scrolls in a 480 x 270 canvas, Batuhan Teacher walks through it with his orange, Grabbo sneaks after it, Pip flies by; the sky follows the clock (`?mood=day|dusk|night` to look at each). The valley (`valley.js`) is the site's own, not one game's: orange groves and a place for each game in `PLACES` (Bluebird School for Pocket Quest; Sunny Hill's island across a bay, with its ship, a villager and a pier; a plot for the next game). A new game: one more entry there (its id, where it stands, its art); its sign takes the game's title and colour from `games.js`. `startStrip` draws "How to play" further down: a strip of the same ground with signposts 1-3, an orange tree, a star, and the teacher walking past them. Everything is drawn with Pocket Quest's pixel engine: `pq-world.js` is a copy of its `px.js`, `font.js` and `world.js` (`node tools/make-world.mjs`, which adds `far()`: the sky, clouds, mountains and hills without the school yard's town and park); the cast is drawn by Pocket Quest's `chars.js` (from `site/`: `node "../../Pocket Quest/tools/shot.mjs" tools/make-cast.mjs tools/pq-cast.html public/img`). |
| `public/js/guide.js` | The full-screen guide: the very first screen on a phone or tablet when the site is opened in a browser (not from the home screen, not on a computer, not after "Bir daha gösterme", not on the way back to a game). How to add Citrobit to the home screen, for Android (Chrome, with a one-tap button when Chrome offers it) or iPhone / iPad (Safari), each step in Turkish and English. `/?rehber=android` or `/?rehber=ios` shows it anywhere. It also keeps Chrome's install offer for the tip on the child's page. |
| `public/js/sfx.js` | The 8-bit sounds, built by ZzFX (MIT, inside the file; no sound files; only after the first tap; the speaker button turns them off), the pixel wipe into the games, and the pixel confetti for a new level. |
| `public/fonts/` | Pixelify Sans and Press Start 2P, served by the site itself (Fontsource woff2 files, OFL licences beside them): no font request goes to Google. |
| `public/index.html` (below the title screen) | Under the world's ground the page is a game's menu: Choose your game (a window per game; its screen pans and cuts through the pictures in `shots` in `games.js`), How to play (the strip), For parents (the teacher's dialog window with an item list). |
| `public/index.html` (the child's top) | After logging in the same world stays: a big hello, days in a row (the server's `play_days`) and the stars, Batuhan Teacher's dialog box, and a window for each game in the login window's style, with a progress bar from its summary line (`levels` in `games.js`; Pocket Quest's `Zone n/m`). What this device showed last time is kept in `oyunSitesi.gordu.<username>`: new stars count up, and a new level, zone or season brings confetti, a fanfare, a "Level up!" ribbon and the teacher's line about it. |
| `public/js/batu.js`, `public/img/ogretmen/` | Batuhan Teacher's dialog box on the child's page, as in a game: his picture with an orange in his hand, the line typed out. Each time the page opens he says a new funny line in simple English (not the same one twice in a row), another one on a tap (the orange hops). The lines are at the top of `batu.js`. |
| `tools/make-teacher.mjs`, `tools/teacher-sprite.html` | His pictures, drawn by Pocket Quest's own character code (`../Pocket Quest/js/gfx/`), so he looks as he does in the game: from `site/`, `node "../../Pocket Quest/tools/shot.mjs" tools/make-teacher.mjs tools/teacher-sprite.html public/img/ogretmen` (the frame sizes go to `tools/teacher-sprite.json`). |
| `shared/names.js` | Usernames: first name + first letter of the surname, plain letters (`Çağla Şen` → `caglas`). |
| `server/api.js` | Everything under `/api/`: logins (PIN as HMAC with the `PEPPER` secret, locks after 5/10/15 wrong tries), saves with versions (409 when another device moved on; `force` wins and backs up the other copy), hourly backups (last 12), the old-save move (one-time code, CORS from the old address only), the teacher's tools. |
| `server/worker.js`, `wrangler.toml` | The Worker: `/api/*` goes to `server/api.js` (`run_worker_first`), everything else is a file from `dist/` (`/oyna` is `oyna.html`; an unknown address shows the front page). |
| `src/oyun-sitesi.js` | The bridge. In a game page it wraps `Storage.prototype.setItem/removeItem/clear`, marks the game's keys that changed, sends them 4 s after a change (at most every 40 s) and at once when the page is hidden; offline changes wait in `oyunSitesi.meta.<game>`. On the pages it is the `window.OyunSitesi` helpers. `build.mjs` prepends the game list and writes `dist/js/oyun-sitesi.js`. |
| `public/` | The pages: `index.html` (login with a PIN pad, the games), `oyna.html` (opening a game: device vs cloud, stash for another child on a shared tablet, the old-save question), `ogretmen.html` (the teacher), `gizlilik.html`, `sw.js` (network first, a kept copy offline). |
| `../tasi.html` | Lives on the old address (GitHub Pages, same origin as both games' old saves): reads one game's keys and posts them to `/api/move/finish` with the code, then goes back. |
| `build.mjs` | `dist/`: Sunny Hill from `origin/main`, Pocket Quest from its web address (`--local`: the files on this computer). Refuses to build when a game's save keys are not where `games.js` expects them. |
| `kur.mjs`, `yayinla.mjs`, `tools/cf.mjs` | First setup and updates through `npx wrangler@4` (login, D1, deploy, secrets, health check). The first deploy may ask for the account's workers.dev name (`citrobit`); the address is read from wrangler's log and written into `shared/config.js`. `npx wrangler@4 deploy --dry-run` checks the Worker without uploading. |
| `tools/dev.mjs`, `tools/d1-node.mjs` | The site on this computer (port 8787; the old address on 8788) with the same `server/api.js` on Node's SQLite. |
| `tools/test-api.mjs`, `tools/test-browser.mjs` | The tests: `node build.mjs --local`, then `node tools/test-api.mjs` (a second) and `node tools/test-browser.mjs` (headless Chrome, two devices, about 3–5 minutes; `GL=gpu` is faster). |

Adding a game: add it to `shared/games.js` (its save keys), to `SOURCES` in `build.mjs` (where it comes from, strings it must contain), and a cover in `public/img/`.

A game that renames its save key would lose the cloud copy's link to it: keep the keys in `games.js` in step (the build stops when they are missing).
